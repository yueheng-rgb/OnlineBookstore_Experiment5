# Jira 看板示例

> **说明**：以下为 Jira 看板的文本示意。需在 Jira 中实际配置后截图。

## Scrum Board 列设置

```
┌──────────┐    ┌──────────────┐    ┌──────────┐
│  To Do   │ →  │ In Progress  │ →  │  Done    │
└──────────┘    └──────────────┘    └──────────┘
```

### To Do 列
- JMeter压力测试
- Jenkins Pipeline配置
- Docker部署配置
- 系统上下文图绘制
- 最终实验报告编写
- 验收清单检查

### In Progress 列
- 单元测试编写
- 需求评审
- 代码注释覆盖率检查

### Done 列
- 用户注册功能开发
- 用户登录功能开发
- 图书CRUD API开发
- 图书搜索功能开发
- 图书分类筛选功能
- 购物车添加商品功能
- 购物车管理功能
- 订单创建功能
- 订单状态管理
- API文档配置
- Git分支策略配置
