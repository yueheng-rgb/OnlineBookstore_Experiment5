# 提交材料清单

## 提交目录结构

```
OnlineBookstore_Experiment5/
├── README.md                          → 项目说明
├── EXPERIMENT_FINAL_REPORT.md         → 最终实验报告
├── MANUAL_OPERATIONS.md               → 人工操作指南
├── DELIVERY_CHECKLIST.md              → 验收清单
├── pom.xml                            → Maven 配置
├── Jenkinsfile                        → Jenkins Pipeline
├── docker-compose.yml                 → Docker 部署
├── src/                               → 源代码
├── docs/                              → 文档
│   ├── 00-project-management/         → 项目管理文档
│   ├── 01-requirements/               → 需求文档
│   ├── 02-system-design/              → 系统设计文档
│   ├── 03-api/                        → API 设计文档
│   ├── 04-testing/                    → 测试文档
│   ├── 05-quality/                    → 质量文档
│   ├── 06-deployment/                 → 部署文档
│   └── 07-submission/                 → 提交说明
├── jira/                              → Jira 材料
├── jmeter/                            → JMeter 材料
├── openapi/                           → OpenAPI 规范
├── scripts/                           → 辅助脚本
└── evidence/                          → 人工证据目录
    ├── screenshots/                   → 【待填充】截图
    ├── video/                         → 【待填充】视频
    ├── signatures/                    → 【待填充】签字扫描
    └── performance/                   → 【待填充】性能报告
```

## 提交方式
1. 将整个 `OnlineBookstore_Experiment5` 目录打包为 ZIP
2. 或推送到 Git 远程仓库并提交仓库链接
3. 确保证据目录中的截图、视频等人工材料已填充
