# Code Review 检查清单

## 代码审查模板

### 基本信息
- **PR 标题**：【填写 PR 标题】
- **作者**：【填写作者】
- **审查者**：【填写审查者】
- **审查日期**：【填写日期】

### 功能性检查
- [ ] 代码是否实现需求规格说明书中描述的功能？
- [ ] 边界条件是否处理（空值、null、超大值）？
- [ ] 是否有潜在的并发问题？

### 代码质量检查
- [ ] 命名是否清晰、符合规范？
- [ ] 注释覆盖率是否 >= 30%？
- [ ] 是否有重复代码？
- [ ] 异常处理是否恰当？

### 安全检查
- [ ] 用户输入是否校验？
- [ ] 敏感信息（密码）是否正确处理？
- [ ] SQL 注入防护（使用参数化查询）？

### 性能检查
- [ ] 是否有 N+1 查询问题？
- [ ] 数据库查询是否使用了索引字段？
- [ ] 缓存策略是否合理？

### 测试检查
- [ ] 是否有对应的单元测试？
- [ ] 测试是否覆盖主要分支？
- [ ] 测试是否能独立运行？

## 审查结论
- ☐ 通过 (Approve)
- ☐ 需修改后重新提交 (Request Changes)
- ☐ 仅评论 (Comment)
