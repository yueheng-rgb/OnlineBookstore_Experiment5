# 测试计划

## 1. 测试目标
确保在线书店系统的所有功能模块正确运行，接口符合规范，性能满足要求。

## 2. 测试范围

### 单元测试
- **工具**：JUnit 5 + Mockito
- **范围**：Service 层、Controller 层
- **覆盖率目标**：>= 70% 代码行覆盖率，>= 30% 注释覆盖率

### 集成测试
- **工具**：Spring Boot Test + MockMvc
- **范围**：完整 API 请求-响应流程

### 压力测试
- **工具**：Apache JMeter 5.x
- **范围**：Redis 缓存读写性能验证
- **场景**：并发用户模拟、缓存命中率测试

## 3. 测试用例

### 3.1 用户模块测试用例

| 编号 | 测试项 | 输入 | 预期结果 |
|------|--------|------|----------|
| UT-01 | 注册新用户 | 合法注册信息 | 201 Created |
| UT-02 | 重复用户名注册 | 已存在用户名 | 400 错误 |
| UT-03 | 正确密码登录 | 正确凭证 | 200 OK |
| UT-04 | 错误密码登录 | 错误密码 | 400 错误 |
| UT-05 | 查询不存在用户 | ID=999 | 404 Not Found |
