# 测试策略

## 测试金字塔

```
        /\
       /E2E\        少量端到端测试 (JMeter)
      /------\
     /集成测试\      中等数量集成测试 (MockMvc)
    /----------\
   /  单元测试   \    大量单元测试 (JUnit 5)
  /--------------\
```

## 测试层次

| 层次 | 工具 | 数量 | 目标 |
|------|------|------|------|
| 单元测试 | JUnit 5 + Mockito | 21个 | Service层全覆盖 |
| 集成测试 | MockMvc | 4个 | Controller层API验证 |
| 上下文测试 | @SpringBootTest | 1个 | 应用启动验证 |
| 压力测试 | JMeter | 6组 | Redis缓存性能对比 |

## 测试数据策略
- 使用H2内存数据库，每次测试重建
- 测试数据与生产数据隔离
- Mock外部依赖（Repository、Service）
