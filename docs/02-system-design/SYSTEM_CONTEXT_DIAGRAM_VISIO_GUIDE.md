# 系统上下文图 Visio 绘制指南

## 准备工作
1. 打开 Microsoft Visio
2. 选择"基本框图"模板
3. 设置页面为A4横向

## 绘制步骤

### 步骤1：系统边界
- 拖入"矩形"形状
- 调整大小覆盖页面中央
- 设置虚线边框
- 添加文字"在线书店系统"

### 步骤2：内部模块
- 拖入4个"圆角矩形"
- 分别标注：用户模块、图书模块、购物车模块、订单模块
- 放置于系统边界内

### 步骤3：外部实体
- 拖入"矩形"形状（虚线边框）
- 放在系统边界外
- 标注：普通客户、管理员、H2/MySQL、Redis、Jenkins

### 步骤4：数据流
- 使用"连接线"工具
- 在系统与外部实体间绘制箭头
- 标注数据流方向

### 步骤5：导出
- 文件 → 导出 → 创建PDF
- 或截图保存PNG
