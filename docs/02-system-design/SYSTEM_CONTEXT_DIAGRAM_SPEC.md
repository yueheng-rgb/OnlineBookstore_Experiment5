# 系统上下文图规范

## 图元规范

| 图元 | Visio形状 | 含义 |
|------|----------|------|
| 大矩形框 | 容器/边界 | 在线书店系统边界 |
| 圆角矩形 | 流程/模块 | 内部模块（用户、图书、购物车、订单） |
| 矩形虚线框 | 外部实体 | 外部系统/用户 |
| 圆柱体 | 数据库 | H2/MySQL |
| 箭头连线 | 连接线 | 数据流方向 |

## 绘制步骤
