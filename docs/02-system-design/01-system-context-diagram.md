# 系统上下文图设计

## 1. 系统上下文图说明

系统上下文图描述了在线书店系统与外部实体（用户、外部系统）之间的交互关系。

### 外部实体

| 实体 | 说明 | 交互方式 |
|------|------|----------|
| 普通客户 | 浏览图书、管理购物车、下单 | HTTP REST API |
| 管理员 | 管理图书、管理用户、处理订单 | HTTP REST API |
| H2/MySQL 数据库 | 数据持久化存储 | JDBC |
| Redis 缓存 | 可选的热数据缓存 | Redis Protocol |
| Jenkins CI | 持续集成构建 | API 触发 |
| Docker 环境 | 容器化部署 | Docker Compose |

## 2. Visio 绘图操作说明

### 步骤
1. 打开 Microsoft Visio
2. 选择"基本框图"模板
3. 绘制系统边界（大矩形框）
4. 添加内部模块（用户、图书、购物车、订单）
5. 添加外部实体（客户、管理员、Jenkins、Redis）
6. 用连线表示数据流
7. 导出为 PDF：文件 → 导出 → 创建 PDF
8. 截图保存到 `evidence/screenshots/system-context-diagram.png`

### Visio 绘图元素说明

| 元素 | Visio 形状 | 说明 |
|------|-----------|------|
| 系统边界 | 矩形/容器 | 表示在线书店系统范围 |
| 内部模块 | 圆角矩形 | 用户、图书、购物车、订单 |
| 外部实体 | 矩形（虚线边框） | 客户、管理员等 |
| 数据库 | 圆柱体 | H2/MySQL |
| 数据流 | 箭头连线 | 表示数据交互方向 |
