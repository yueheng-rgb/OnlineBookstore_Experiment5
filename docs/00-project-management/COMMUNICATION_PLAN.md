# 沟通计划

## 会议安排

| 会议 | 频率 | 时长 | 参与人 |
|------|------|------|--------|
| 每日站会 | 每日 | 15分钟 | 全员 |
| Sprint Planning | 每Sprint开始 | 1小时 | 全员 |
| Sprint Review | 每Sprint结束 | 30分钟 | 全员 + PO |
| Sprint Retrospective | 每Sprint结束 | 30分钟 | 全员 |
| 需求评审会 | 一次性 | 10分钟 | PO + SM + Dev + QA |

## 沟通渠道

| 渠道 | 用途 |
|------|------|
| 微信群/钉钉 | 日常沟通 |
| GitHub Issues | 缺陷和工作跟踪 |
| GitHub Pull Request | Code Review |
| Jira | 任务管理和进度跟踪 |
