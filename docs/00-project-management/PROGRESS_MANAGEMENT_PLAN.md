# 进度管理计划

## 进度跟踪方法

1. **Jira Scrum Board**：三列状态 (To Do → In Progress → Done)
2. **Burndown Chart**：基于Story Points的燃尽图
3. **每日站会**：更新昨日进度、今日计划、障碍

## 进度指标

| 指标 | 目标 | 实际 |
|------|------|------|
| Sprint完成率 | >=80% SP完成 | Sprint 1-3: 100% |
| 代码提交频率 | >=5 commits/周 | - |
| PR Review时间 | <24小时 | - |

## 延期处理
- 黄色预警：SP完成率<70%时通知SM
- 红色预警：SP完成率<50%时升级到PO，协商范围调整
