# Swagger 使用指南

## 访问地址
- Swagger UI：`http://localhost:8080/swagger-ui.html`
- OpenAPI JSON：`http://localhost:8080/v3/api-docs`

## 使用步骤
1. 启动应用：`mvn spring-boot:run`
2. 打开浏览器访问 Swagger UI
3. 选择一个API分组（如"图书管理"）
4. 展开具体接口，点击"Try it out"
5. 填写参数，点击"Execute"
6. 查看响应结果
