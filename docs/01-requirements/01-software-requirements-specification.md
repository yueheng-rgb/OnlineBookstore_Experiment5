# 软件需求规格说明书 (SRS)

> 参考 IEEE 830-1998 标准结构编写

## 1. 引言

### 1.1 目的
本文档旨在定义在线书店系统的功能需求和非功能需求，作为项目开发、测试和验收的依据。

### 1.2 范围
在线书店系统是一个基于 Web 的电子商务平台，允许用户浏览图书、管理购物车、提交订单，支持管理员进行图书管理和订单处理。

### 1.3 定义与缩写
| 术语 | 定义 |
|------|------|
| SRS | Software Requirements Specification |
| API | Application Programming Interface |
| CRUD | Create, Read, Update, Delete |
| JPA | Java Persistence API |

## 2. 总体描述

### 2.1 产品视角
本系统采用前后端分离架构，后端提供 RESTful API，支持多种客户端（Web、移动端）。

### 2.2 用户特征
- **普通客户**：浏览图书、管理购物车、下订单
- **管理员**：管理图书、管理用户、处理订单

### 2.3 约束
- 后端使用 Java 17 + Spring Boot 3.x
- 默认使用 H2 内存数据库，可选 MySQL
- 默认使用本地缓存，可选 Redis

## 3. 具体需求

### 3.1 用户管理模块
- **注册**：用户可注册账号（用户名、密码、邮箱）
- **登录**：用户可使用用户名和密码登录
- **信息管理**：用户可查看和更新个人信息

### 3.2 图书管理模块
- **图书浏览**：分页浏览所有图书
- **图书搜索**：按书名、作者搜索
- **分类筛选**：按分类浏览图书
- **图书管理**（管理员）：添加、更新、删除图书

### 3.3 购物车模块
- **添加商品**：将图书加入购物车
- **修改数量**：调整购物车中商品数量
- **移除商品**：从购物车中移除商品
- **清空购物车**：一键清空购物车

### 3.4 订单模块
- **创建订单**：从购物车生成订单
- **订单查询**：查看订单列表和详情
- **状态管理**：更新订单状态
- **取消订单**：取消订单并恢复库存

## 4. 非功能需求

| 类别 | 需求 |
|------|------|
| 性能 | API 响应时间 < 500ms (P95) |
| 可用性 | 支持 Redis 不可用时的降级运行 |
| 安全性 | 密码哈希存储，参数校验防止注入 |
| 可维护性 | 代码注释覆盖率 >= 30% |
| 可扩展性 | RESTful API 设计，支持水平扩展 |
