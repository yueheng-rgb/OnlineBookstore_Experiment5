# 用户角色画像

## 角色 1：普通客户 - "爱书人小林"

### 背景
- 姓名：小林
- 年龄：25 岁
- 职业：软件工程师
- 技术熟练度：高

### 目标
- 快速搜索和浏览技术图书
- 将感兴趣的书加入购物车
- 一次性下单购买多本书

### 使用场景
1. 小林想买一本关于 Spring Boot 的书
2. 他打开在线书店，搜索 "Spring"
3. 找到《Spring实战》，查看价格和库存
4. 将书加入购物车，又添加了一本《算法导论》
5. 确认购物车后，填写地址提交订单

### 核心需求
- 快速搜索
- 清晰的图书信息展示
- 便捷的购物车管理
- 流畅的下单体验

## 角色 2：系统管理员 - "管理员老张"

### 背景
- 姓名：老张
- 年龄：35 岁
- 职业：系统管理员
- 技术熟练度：高

### 目标
- 管理图书目录（上架新书、更新信息、下架）
- 管理用户信息
- 处理订单状态
- 监控系统运行

### 使用场景
1. 出版社寄来了新书，老张在后台添加图书信息
2. 某图书涨价，老张更新图书价格
3. 某订单已发货，老张更新订单状态为 SHIPPED

### 核心需求
- 完整的图书 CRUD 能力
- 订单状态管理
- 用户信息管理
