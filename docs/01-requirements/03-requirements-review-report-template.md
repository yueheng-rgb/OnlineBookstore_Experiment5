> 本次评审目标是确认功能需求和非功能需求的完整性和可行性。"

### 功能介绍 (3 分钟)
> "系统包含四大模块：用户管理、图书管理、购物车、订单管理。
> 用户可注册登录、浏览搜索图书、管理购物车、提交订单。
> 管理员可管理图书信息、处理订单状态。"

### 技术方案 (2 分钟)
> "技术栈采用 Java 17 + Spring Boot 3.x，默认 H2 数据库。
> 支持可选部署 MySQL 和 Redis，具备缓存降级能力。"

### 讨论与确认 (3 分钟)
> "请大家就功能范围、技术选型、非功能需求提出意见。"
